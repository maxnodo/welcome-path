WCE Welcome — Immigration & Foreign Affairs

Sistema de gestión de casos para despacho de extranjería en Barcelona. Plataforma integral que conecta usuarios, gestores y administradores en un flujo de trabajo unificado para trámites migratorios.

Roles del Sistema

RolAccesoDescripción
Admin Total Acceso completo. Gestiona usuarios, configuración y ve todos los datos del sistema.
Gestor Parcial Gestiona solo los expedientes asignados. Sin acceso a configuración ni gestión de usuarios.
User Propio Ve únicamente sus propios datos: perfil, trámites, mensajes, alertas, citas y facturas.

  • El usuario se pre-inscribe vía FormularioExpress en la pestaña de login
  • Se crea un registro en la tabla leads con estado pending

Multi-gestor Scoping

Cada gestor ve exclusivamente los datos vinculados a sus expedientes asignados. El scoping se aplica en todas las pantallas del panel admin/gestor:

PantallaFiltro para Gestor
Expedientesexpedientes.advisor_id = auth.uid()
Citascitas.advisor_id = auth.uid()
Mensajesmensajes.sender_id = uid OR receiver_id = uid
AlertasINNER JOIN expedientes ON alertas.expediente_id = expedientes.id WHERE expedientes.advisor_id = auth.uid()
  • Expedientes: filtrado por advisor_id
  • Citas: filtrado por advisor_id
  • Mensajes: filtrado por sender_id o receiver_id
  • Alertas: inner join con expedientes por advisor_id
  • El admin siempre ve todos los datos sin restricción
